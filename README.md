# Лабораторная работа №4

Самоорганизующаяся карта Кохонена. Вариант 10, 17 двухмерных объектов из таблицы задания.

## Запуск

```bash
./script.sh
```

Скрипт собирает программу и открывает меню. Пункт 1 строит график исходных точек. Пункт 2 обучает оба варианта карты, сравнивает результаты и сохраняет графики в `plots/`. Начальная скорость обучения задаётся от 0,3 до 0,7. По умолчанию используется 0,5. Для сборки нужны CMake и компилятор с поддержкой C++17.

## Обучение

На [графике исходных точек](plots/01_points.svg) видно пять компактных групп в окрестностях `(-19, -17)`, `(-9, -6)`, `(2, -4)`, `(10, -3)` и `(18, -11)`. Поэтому у карты пять выходных нейронов.

Каждый вход и каждый случайный начальный вес нормируются по евклидовой длине. Начальные веса генерируются в нижней полуплоскости, где находятся все точки варианта 10. Порядок объектов перемешивается на каждой из 100 эпох. В обоих запусках используются одни и те же начальные веса и перестановки с seed 10. После каждой эпохи скорость обучения умножается на 0,96.

Победитель определяется по максимальному скалярному произведению входа и веса. Обновляется только вес победителя по формуле `w ← w + η(x − w)`, затем он снова нормируется. В режиме с утомляемостью перед выбором победителя из скалярного произведения вычитается накопленный штраф. После выбора все штрафы умножаются на 0,85, а к штрафу победителя прибавляется 0,08. Итоговая классификация использует обученные веса без штрафов.

В исходных координатах центр кластера — среднее его точек. Для единичного веса `w` и центра `c` масштабированный вектор равен `max(0, c·w) w`. Его конец — ближайшая к центру точка на луче веса. Для пустого кластера центр и масштабированный вектор не вычисляются.

## Результаты

При начальной скорости 0,5 в классическом режиме распределение по пяти нейронам — 0, 1, 2, 8 и 6 точек. При утомляемости — 3, 3, 5, 3 и 3 точки. Утомляемость задействовала все нейроны, но среднее расстояние нормированного входа до веса победителя выросло с 0,0969 до 0,1167. Нормировка сохраняет угол и убирает различия в длине, поэтому группы на исходном графике и кластеры карты могут различаться.

Время измеряется как медиана 101 запуска каждого алгоритма. В замер входит цикл обучения, включая создание массива штрафов. Инициализация весов, подготовка перестановок, итоговая классификация и построение графиков выполняются вне замера.
В контрольном запуске медианы составили 53,6 мкс для классического алгоритма и 58,7 мкс для алгоритма с утомляемостью. При повторном запуске абсолютные значения могут меняться.
